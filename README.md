## 📌 Workflow & Contribution Guidelines

### 1. Personal Folder Maintenance
- Keep all your research notes within your assigned root folder (e.g., `your-name/`).
- Use clear subfolders or naming conventions for specific days, topics, or literature reviews (e.g., `Day 1/`, `topic-literature/`).

### 2. Note-Taking Recommendations
When summarizing research papers or topics, try including:
- **Title & Source / Link**: Direct reference to the original publication.
- **Key Takeaways & Findings**: Core ideas, parameters, methodologies, or theories (e.g., *Faster-is-Slower* vs *Faster-is-Faster*).
- **Project Relevance**: How the research translates to our system architecture, modeling/simulation layer, monitoring logic, or CV/AI algorithms.

### 3. Git Etiquette
- Commit regularly with meaningful commit messages (e.g., `feat: add research summary on pedestrian crowd dynamics`).
- Pull changes before starting a work session to stay updated on teammates' progress.
- Avoid modifying files inside another team member's folder without prior coordination.
